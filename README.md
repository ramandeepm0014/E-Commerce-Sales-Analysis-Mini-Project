# 🛒 E-Commerce Sales Analytics

An end-to-end **Data Analytics Mini Project** that demonstrates the complete analytics workflow using **Excel, Python, and Power BI**. This project focuses on transforming raw e-commerce sales data into meaningful business insights through data cleaning, exploratory data analysis (EDA), feature engineering, and interactive dashboard creation.


# 📌 Project Overview

The objective of this project is to analyze an e-commerce sales dataset and identify valuable business insights. The project covers the complete data analytics pipeline, starting from raw data auditing and cleaning to data visualization and dashboard development.


# 🎯 Project Objectives

* Perform data auditing and cleaning.
* Handle missing, duplicate, and inconsistent data.
* Explore sales trends using Exploratory Data Analysis (EDA).
* Detect statistical outliers.
* Perform feature engineering.
* Create interactive dashboards for business insights.
* Present data visually for better decision-making.
